# Agent Instructions

You are working on TeamFlow Ops, a frontend-heavy full-stack portfolio project.

## Main goals
- Build production-like React + TypeScript code.
- Prefer small, focused iterations.
- Keep the app working after every change.
- Do not implement large unrelated features in one task.
- Do not rewrite the whole project unless explicitly asked.

## Tech stack
Frontend:
- React
- TypeScript
- Vite
- Redux Toolkit / RTK Query later
- React Hook Form + Zod later
- CSS Modules or Tailwind

Backend:
- Node.js
- Express
- TypeScript
- MongoDB/Mongoose later

## Code style
- Use clear names.
- Prefer small components.
- Keep business logic outside UI components when possible.
- Add loading, error and empty states where relevant.
- Avoid overengineering.

## Git rules
- One task should result in one small logical change.
- Use Conventional Commits:
  - feat:
  - fix:
  - chore:
  - docs:
  - refactor:
  - test:
- Before finishing, explain what changed and how to test it.

## Definition of Done
- Code compiles.
- No obvious TypeScript errors.
- The app can be started locally.
- README or ROADMAP is updated if the task changes project behavior.
